# Política de privacidad

Esta aplicación es un proyecto de automatización personal creado con fines de aprendizaje y portafolio.

## Acceso a los datos
La aplicación accede a datos limitados de LinkedIn y GitHub únicamente para:
- Leer información de commits de GitHub de repositorios propiedad del desarrollador.
- Publicar posts en el perfil de LinkedIn del propio desarrollador.

## Almacenamiento de datos
No se almacenan, comparten ni venden datos personales.
Todos los datos se procesan de forma transitoria durante la ejecución de la automatización.

## Terceros
No se comparten datos con terceros.
